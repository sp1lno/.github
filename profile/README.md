# sp1lno

Спільний простір роботи над одним продуктом: дизайн, Frontend, Backend та Admin Panel.

Код і внутрішня документація зберігаються у приватних репозиторіях організації. Доступ надається учасникам відповідно до їхніх ролей.

Публічні відомості про продукт і контакт для звернень будуть додані після погодження.
