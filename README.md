# Організаційні матеріали sp1lno

Цей публічний репозиторій містить [профіль організації](profile/README.md) та загальні правила внесення змін.

Код, приватні дизайн-посилання, вимоги й робочі задачі продукту зберігаються окремо у приватному репозиторії організації. Не додавайте сюди внутрішні дані, секрети або персональні дані.
